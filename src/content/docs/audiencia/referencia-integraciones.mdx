Esta página recoge todos los proveedores de integración disponibles en Nevent en el momento de escribir esta guía, la categoría a la que pertenece cada uno y la credencial exacta que te pide el formulario de conexión.

Úsala como consulta rápida antes de conectar una fuente de datos, para saber de antemano qué necesitas tener a mano.

## Proveedores disponibles

| Proveedor | Categoría | Qué necesitas para conectarlo |
|---|---|---|
| Onebox | Ticketing | Client secret |
| Fourvenues | Ticketing | Channel Manager API e Integrations API |
| Enterticket | Ticketing | Usuario y contraseña |
| Covermanager | Ticketing | Cookie |
| DICE | Ticketing | API Token |
| CASFID | Cashless | Token de autenticación y mapeo de eventos (ID de evento CASFID vinculado a un ID de evento en Nevent) |
| XCEED | Ticketing | API Key |
| Fever | Ticketing | Usuario (email) y contraseña |

:::note[Nota]
Estas credenciales te las facilita tu proveedor de ticketing o cashless, normalmente desde su propio panel o a través de su equipo de soporte. Nevent no las genera por ti.
:::

## Qué aporta cada categoría

**Ticketing.** Son los proveedores de venta de entradas: Onebox, Fourvenues, Enterticket, Covermanager, DICE, XCEED y Fever. Al conectarlos, Nevent incorpora a tu audiencia los datos de ventas y asistentes que se generan en cada uno de ellos.

**Cashless.** CASFID pertenece a esta categoría. Sincroniza transacciones de consumo dentro del recinto (recargas de saldo, pagos con pulsera o tarjeta cashless), no ventas de entradas. Requiere además un paso adicional de configuración: mapear cada evento de CASFID con su evento correspondiente en Nevent.

## Cómo llegar a esta pantalla

Entra en **Configuración → Integraciones**. Ahí verás dos pestañas:

- **Integraciones:** muestra las conexiones activas de tu organización y, mediante el botón **Añadir integración**, el catálogo completo de proveedores disponibles.
- **Tokens API:** gestiona tokens para autenticar peticiones a la API o a webhooks de Nevent. No está relacionado con conectar una ticketera; sirve para integraciones a medida que tu equipo técnico construya contra Nevent.
