## The problem they solve

When you promote an event, you share a lot of links: the tickets page, an explainer video, the venue map, the announcement for a giveaway. Those links tend to be long, unclear, and — most importantly — invisible: you don't know whether anyone clicked them or not.

A Magic Link solves both problems at once. It turns any long URL into a short link under the `nevt.link` domain, and it records every time someone taps it.

## What a Magic Link is, exactly

A Magic Link is a short, trackable link that Nevent generates for any URL you provide. When someone clicks it, Nevent records that click and redirects the person to the original destination in under a second.

For example, instead of sharing:

```
https://demofest.nevent.es/event/demo-fest-2026-entradas
```

you share:

```
https://nevt.link/2h92bh
```

Both lead to the same place, but the second one tells you how many people came through.

The **Magic links** section, inside **Tools**, centralizes every link in a single list, regardless of how it was created. The description shown on the screen itself sums up its purpose well: "One link per destination, with its full history, whether it was generated by a campaign, the assistant, or you."

## Where Magic Links come from

In Nevent, a Magic Link can have three different sources:

**Manual.** You create it yourself from the Tools section. You give it a title that helps you identify it (for example, "Tickets Demo Fest - IG Bio") and it points to whatever URL you choose. This type gives you the most control: it has the "More options" button available, and you can use it wherever you want.

**From campaigns.** When you launch an email or SMS campaign in Nevent, the platform automatically generates a Magic Link for every URL you include in the message. This happens without you having to do anything. Those links are logged in the list with the source "Campaigns" and the "Managed by the platform" icon.

**From assistant.** Nevent's chatbot also generates Magic Links when it shares a URL with someone who asks, for example, where to buy tickets. They appear in the list with the source "Assistant" and the same automatic-management icon.

The list shows all three types together, with filters to view them separately if you need to.

## What information each Magic Link records

For each link, the list shows:

- **Total clicks**: the cumulative number of times someone has tapped that link since it was created.
- **Used in**: how many Nevent campaigns include that Magic Link. If none do, a dash appears.
- **Last click**: the date and time of the most recent click.

Each row also has a button to expand the link's detail with additional information.

## When it makes sense to create a manual Magic Link

The automatic sources (campaigns and assistant) cover the usual cases without any effort on your part. A manual Magic Link makes sense in situations like these:

**Instagram or TikTok bio.** You can only put one link in your bio, and you want it to be short and to tell you how many people use it.

**Posters and QR codes.** A QR code points to a URL, and if that URL is a Magic Link, you know how many people scanned the poster and when.

**WhatsApp groups, Telegram, or communities.** Long messages with kilometre-long URLs look bad. A clean `nevt.link/` is easier to tap and gives a better impression.

**Measuring channels separately.** If you want to know whether your Telegram community converts better than your Instagram bio, create a different Magic Link for each channel pointing to the same destination. That way the clicks don't get mixed together and you can compare them.

**Any URL you want to reuse with tracking.** A Spotify playlist, a presentation video, a survey: any link you're going to share repeatedly and want to know the reach of.

## When you don't need to create one

If you're sending an email or SMS campaign in Nevent, the platform already creates the Magic Links for you. There's no need to create them by hand beforehand. If you later want to check the clicks, you'll find them in the list with the source "Campaigns."

In the same way, when the chatbot assistant shares a URL in a conversation, it generates its own Magic Link. It will appear in the list with the source "Assistant."

## The "one link per destination" logic

An important detail: Nevent groups all the clicks on a single Magic Link into one record, no matter how many times or from where that link was shared. If you create a Magic Link for the tickets page and put it in three different places, the clicks from all three are added together in the same counter.

This has an advantage: that link's accumulated history is never lost. If you use the same destination again next year, you can see everything it has generated from the start.

It also has a practical consequence: if you need to distinguish traffic by channel, you have to create one Magic Link per channel, even if they all point to the same place. That's precisely why some promoters have several Magic Links with titles like "Tickets - IG Bio," "Tickets - Stories" or "Tickets - BACCHANALIA Poster."

## What Magic Links are not

To avoid confusion, it's worth clarifying what a Magic Link doesn't do:

They're not payment or affiliate links. They simply redirect and count clicks.

They don't personalize the destination based on who clicks. Everyone who taps the same Magic Link ends up at the same place. (Personalization per contact happens inside campaigns, not in manual Magic Links.)

They don't replace campaign analytics. Magic Links measure clicks on a link. Campaign analytics measures opens, conversions and other metrics for the send as a whole. They complement each other.
