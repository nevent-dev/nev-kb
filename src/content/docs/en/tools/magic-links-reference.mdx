Magic Links is the Tools section that centralizes all the short links in your account. This page describes the properties of each link, the table columns, and how behaviour differs depending on the source.

<Aside type="tip">
If you're looking for the steps to create a manual Magic Link, see the guide [Magic Links: Shorten Links and Track Clicks](/en/tools/magic-links).
</Aside>

---

## Short domain

All of Nevent's Magic Links are published under the `nevt.link` domain. The format of any short link is:

```
https://nevt.link/XXXXX
```

where `XXXXX` is the unique alphanumeric code assigned by the platform. This code cannot be changed by the promoter.

---

## Sources of a Magic Link

Every Magic Link has a source that indicates who or what created it. The table's **Source** column can show three values.

| Source | Who creates it | When it appears |
|--------|---------------|----------------|
| **Manual** | The promoter, from the Magic Links screen | When the creation form is used |
| **Campaigns** | The platform, automatically | When a URL is included in an email campaign |
| **Assistant** | Nevent's chatbot, automatically | When the assistant generates a link in a conversation |

All three sources share the same short domain, `nevt.link`, and appear in the same list. The view filters at the top let you show only links from one specific source.

---

## Columns of the Magic Links table

The table shows the following columns for each link.

| Column | Description |
|---------|-------------|
| **Destination** | The link's title if one has been assigned; otherwise, the full destination URL. |
| **Source** | Value: Manual, Campaigns, or Assistant. |
| **Link** | The short link in `nevt.link/XXXXX` format, hyperlinked to open the destination directly. |
| **Total clicks** | Numeric counter of the cumulative total of clicks recorded since the link was created. |
| **Used in** | Number of Nevent campaigns that reference that link. Shows a dash if no campaign uses it. |
| **Last click** | Date and time of the last recorded click. Stays empty if the link hasn't received any clicks. |
| **Actions** | Buttons available for that link (see the next section). |

---

## Actions available by source

The set of actions shown in the **Actions** column varies depending on the link's source.

| Action | Manual | Campaigns | Assistant |
|--------|--------|----------|-----------|
| Expand detail | Yes | Yes | Yes |
| More options | Yes | No | No |
| "Managed by the platform" icon | No | Yes (on some) | Yes |

The **Expand detail** button is present on every record. The **More options** button only appears on links with a Manual source.

---

## What "managed by the platform" means

Links with a Campaigns or Assistant source show an icon indicating that Magic Link is managed by the platform. This has the following implications:

- The link can't be modified or deleted from the promoter interface.
- The **More options** button doesn't appear in the Actions column.
- The link stays in place as long as the campaign or the assistant conversation that originated it remains active.

Links with the text "Auto-generated from campaign" in the Destination field have a **Manual** source and do have the **More options** button available: the promoter can edit or delete them like any other manual link. The descriptive title indicates that the link points to a destination previously used in a campaign, but it doesn't mean the platform manages it.

## Filters and search box

The Magic Links screen offers two mechanisms for locating links.

| Element | Options |
|----------|---------|
| **View filters** | All (default), Manual, From campaigns, From assistant |
| **Search box** | Searches by text in the destination, title, or link code |

The view filters and the search box work together.

---

## Metrics visible in the list

The main table shows two usage metrics for each link directly:

- **Total clicks**: sum of all clicks received since creation, with no way to filter by date from the list.
- **Last click**: timestamp of the most recent click. If the link hasn't received any clicks, this field appears empty.

The **Used in** field isn't a click metric, but a reach one: it indicates how many campaigns that link appears in.

### Scope of the measurement

A Magic Link measures **clicks, not sales**. That's a consequence of how it works: when you distribute a link on your own — a QR code on a poster, a social media post, a link you hand to your street team — whoever opens it is an anonymous visitor, and any purchase they make afterward isn't linked to that click.

This isn't a flaw in the link, it's the difference between two distinct situations:

| Situation | What's measured |
|---|---|
| Link **inside a Nevent campaign** | Clicks per fan, post-click conversion, and attributed revenue. Nevent knows who the message was sent to |
| Link **you distribute yourself** | Number of clicks, with origin, device, browser and timestamp. No sales data |

Links you distribute on your own are still the best tool you have for comparing channels that would otherwise leave no trace at all, such as posters or radio. What you get from that comparison is a traffic split by channel, and it's worth reading it as exactly that.

<Aside type="note">
The **Expand detail** panel on each row can contain additional statistics broken down by period or other dimensions. The exact contents of that panel aren't covered in this reference.
</Aside>

## Pagination

The list shows 20 records per page. If you have more than 20 Magic Links, pagination appears at the bottom to navigate between pages.
