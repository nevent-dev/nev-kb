In this guide you'll learn to create an email template from scratch using Nevent's visual editor. You don't need any design or coding knowledge. In about 10 minutes you'll have a template ready to use in your campaigns.

## Before you start

Email templates are the visual "mould" you reuse across your campaigns. You can have several: one for newsletters, another for early birds, another for transactional messages. Design them once here and use them as many times as you want.

If you already have a template and just want to edit it, go straight to [step 3](#step-3-open-the-template-in-the-editor).

## Step 1: Go to Templates

In the side menu, click **Templates**, inside the Campaigns section.

The template library opens. The default active tab is "Email templates".

:::tip[Tip]
Use the search box at the top of the list to find a template by name once you have many saved.
:::

## Step 2: Create a new template

Click the **Design** button (top-right corner) and choose **Email** from the menu that appears.

The visual editor opens with a base template already prepared: logo, main image, two-column text, call-to-action button and email footer.

:::note[Note]
If you want to edit a template that already exists, click the three dots on its card and choose **Edit**. Or click its thumbnail to preview it first and then click **Edit template**.
:::

## Step 3: Open the template in the editor

The editor has three main areas:

- **Left panel:** blocks you can add and styling options.
- **Centre:** the canvas where you see the email as your fan will see it.
- **Top bar:** actions for saving, signing off, previewing and sending a test.

## Step 4: Add and edit blocks

The left panel has two sections.

**Content:** content blocks you drag into the email:

| Block | What it's for |
|--------|---------------|
| Text | Editable paragraph of text |
| Button | Button with a link (for tickets, bookings, etc.) |
| Image | Photo or image of the poster, artist or venue |
| Divider | Separator line between sections |
| Social | Social media icons |
| Spacer | Empty space to separate blocks |
| Hero | Large image block with text on top |
| Navbar | Navigation menu |
| HTML block | Custom HTML code |

**Layout:** column structures to organise your content (1 column, 2 columns 50/50, 2 columns 25/75...).

To add a block: drag it from the panel to the place in the email where you want it to appear.

## Step 5: Edit the content of a block

Click any block on the canvas to select it. Selecting it does two things:

1. Floating controls appear over the block: move, duplicate, delete and more options.
2. The left panel switches to **Styles**, where you can adjust size, margins, typography and colour.

To edit the text of a block: double-click on it and type directly.

:::tip[Tip]
When you select a text block and switch to the **Styles** tab, you can change the font, size, colour and weight of the text without touching any code. Experiment until the design matches your event's identity.
:::

## Step 6: Preview how it will look on mobile

In the top bar, use the desktop and mobile icons to switch the preview. This lets you check the design looks good in both formats before you send it.

## Step 7: Send a test email

Before saving for good, you can send the email to yourself to see it in your real inbox. Click **Test** (top-right corner).

The "Preview and test" panel opens with:

- **Preview** on desktop and mobile.
- **Preview with user data:** search for a real contact to see how the personalisation fields (name, etc.) would look with real data.
- **Subject:** type the subject line of the test email.
- **Send test:** enter your email and click "Send test".

:::note[Note]
The test email is sent with the personalisation data of the contact you chose, or with blank values if you didn't select one. Check that the personalisation fields look right before using the template in a real campaign.
:::

## Step 8: Save the template

When you're happy with the design, click **Save as** in the top bar.

The "Save template" dialog appears:

- **Template name:** give it a descriptive name (250 characters max). For example: "Early bird June 2026" or "Monthly newsletter".
- **Folders:** group the template into a folder if you use several (optional).

Click **Save as** to confirm.

## Result

Your template appears saved in the Email Templates list with its preview. From now on you can select it when creating any email campaign.

Using the three-dot menu on each card you can: **edit**, **rename**, **clone** (duplicate it as a starting point for another campaign) or **preview** the template.

:::tip[Tip]
Clone a template that already works well and only change what needs to change (date, image, button). This keeps visual consistency across campaigns and saves you time on every send.
:::
